## Scope and corrections

- MouadVision semantic search and real payment integration remain future work; ranking predictions are marked experimental.
- Mira frontend responses are simulated. Its proposed Next.js/PostgreSQL integration is not presented as delivered.
- Mira language adaptation includes SFT experiments and preparation for CPT; native Darija fluency is not presented as a solved result.
- Leyton's 67.5% to 81.7% information-capture result is contextualized as a two-call evaluation. GraphRAG is related work, not the implemented Elasticsearch retrieval architecture.
- Microgrid performance belongs to a simulation-based competition project. The stress-analysis application is educational, not a medical diagnostic tool.
- The optimization research is a literature synthesis and framework design; no publication or benchmark superiority is claimed.

## Verification

Run `npm run test` and `npm run build`. The browser QA script uses an isolated headless Chrome profile, checks all archive and profile counts, exercises filters/search, opens dialogs, checks Escape/focus restoration, checks the research Ask response, and verifies desktop, mobile, and reduced-motion behavior.

`PORTFOLIO_QA_URL` can point `node scripts/browser-qa.mjs` to a production preview. Local screenshots and machine-readable results are written to the ignored `qa/current/` directory. Large original reports are only requested when their links are opened; they are not part of the initial JavaScript bundle.

The ENSAKH presentation was losslessly optimized for GitHub on 2026-10-22, reducing its size from 226,840,573 to 6,457,310 bytes by deduplicating PDF objects and compressing streams. All 44 pages retain identical extracted text, links, bookmarks, dimensions, and rendered pixel hashes at 100 dpi. No image resampling was applied, and the supplied original in Downloads remains untouched.
